# 家用模拟阳光自动化系统 - 完整方案

## 项目概述

基于南光FS-300B双色温LED灯 + FL-20G菲涅尔透镜，搭建一套可通过华为智慧生活APP远程控制的自动化"模拟阳光"照明系统。灯体可在3.5米电动滑轨上遥控移动，灯头接双轴电动云台遥控调角，菲涅尔透镜电动调焦，通过HomeAssistant作为中枢统一调度，华为智慧生活APP选择场景时一键切换滑轨位置+照耀角度+灯光参数+透镜角度。

## 四个预设场景

| 场景 | 滑轨位置 | 云台俯仰 | 云台旋转 | 透镜光束角 | 灯亮度 | 灯色温 |
|---|---|---|---|---|---|---|
| ① 早晨唤醒 | 0mm（床头） | 下倾30° | 0° | 38°（大光斑） | 50% | 5000K |
| ② 上午运动 | 1100mm（运动区） | 下倾20° | 0° | 30°（中光斑） | 60% | 5000K |
| ③ 工作写字 | 2300mm（书桌） | 下倾35° | 0° | 25°（聚焦） | 70% | 4500K |
| ④ 电视模拟窗 | 3500mm（电视旁） | 下倾45° | -30° | 20°（窄光束） | 40% | 3500K |

## 二、代码文件说明

所有代码位于 `code/` 目录：

| 文件 | 说明 | 部署位置 |
|---|---|---|
| `esphome_slider.yaml` | 3.5米电动滑轨ESPHome配置（TMC2209+57步进，位置0-3500mm，4个预设位置按钮） | 刷入滑轨ESP32 |
| `esphome_gimbal.yaml` | 双轴云台+菲涅尔调焦ESPHome配置（双TMC2209+57步进×2+MG996R舵机，俯仰/旋转/光束角控制，4个场景预设） | 刷入云台ESP32 |
| `ha_automations.yaml` | HomeAssistant四个场景自动化脚本（滑轨移动→云台调角→透镜调焦→灯亮渐变，含定时触发） | HA的automations.yaml |
| `ha_configuration.yaml` | HA辅助配置（input_boolean场景触发器、状态传感器、shell_command调用蓝牙脚本） | HA的configuration.yaml |
| `fs300b_control.py` | FS-300B蓝牙控制Python脚本（基于nanlite-reverse-engineering，支持开关/亮度/色温/状态查询，BLE Mesh协议） | HA的scripts/目录或命令行 |
| `generate_stl.py` | 3D打印STL批量生成脚本（Python+numpy-stl，生成6类零件） | 本地运行 |
| `gears_openscad.scad` | 精确齿轮OpenSCAD设计（调焦齿轮环60齿+舵机齿轮15齿+舵机支架参数化，渐开线齿形） | OpenSCAD打开渲染导出STL |

### 部署步骤

1. **HA主机**：树莓派5刷HAOS，安装HACS，配置Matter桥接
2. **ESP32**：用ESPHome Web刷入两个yaml配置，接入HA
3. **FS-300B蓝牙**：从安卓NANLINK APP提取mesh密钥，填入`fs300b_control.py`，测试控制
4. **HA自动化**：将automations和configuration配置导入HA
5. **华为智慧生活**：添加Matter设备（HA暴露的input_boolean），创建4个场景卡片

## 六、关键注意事项

1. **3.5m滑轨顶棚固定**：铝型材+电机总重约10-12kg，必须用M8膨胀螺栓固定在混凝土顶棚或实木龙骨上，每隔70cm一个固定点（共5个），不能只固定石膏板。

2. **滑轨走线**：滑车移动时线材跟随，必须用拖链（坦克链）收纳，3.5m行程建议15×20规格拖链。

3. **步进电机噪音**：TMC2209 StealthChop模式下约30-35dB，场景切换持续3-8秒。比空调低档略高但可接受。

4. **FS-300B散热**：顶棚安装留5cm散热空间，350W满功率长时间运行建议开智能风扇模式（24dB）。

5. **FL-20G调焦环尺寸**：脚本中齿轮环内径按185mm设计，实际打印前务必用卡尺实测FL-20G调焦环外径，修改参数后再打印。

6. **蓝牙mesh密钥**：FS-300B的蓝牙控制需要从安卓设备提取NANLINK的mesh密钥，这是整个项目最复杂的软件环节。如提取困难，可先用华为智选插座控制电源通断+NANLINK APP预设亮度色温（断电记忆恢复）作为过渡方案。
