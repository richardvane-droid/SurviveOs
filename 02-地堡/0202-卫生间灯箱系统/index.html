DESIGN PHILOSOPHY

为什么这样设计

💡

无窗，就要自己造光

30㎡ 密闭地堡没有任何采光，传统做法是装一排灯。本方案反其道而行：把 2㎡ 卫生间整体做成"灯箱"，让整个空间从"被照亮"变成"被喂光"——门一开，光自己灌进来。

🔑

六面镜，光出不去也逃不掉

四面墙 + 顶 + 地共 16.7㎡ 全铺镜面不锈钢马赛克，反射率 0.6~0.85。光在盒内被反复"困住"叠加，形成无限镜效应；即便反射 5~8 轮仍有上千流明幸存，足以穿门而出。

♨️

浴霸 = 光 + 热一体

1000W 卤素灯暖浴霸 ≈19,000 lm 可见光（光）+ 900W 红外热（热）。一盏灯同时是主照明和主供暖，一石二鸟，绝不浪费一瓦。

🪟

玻璃门 = 光窗 + 红外热窗

超白高透玻璃对可见光透射 ≈90%，对卤素主波长的近红外也有 70~85% 透射。所以门关着也在向地堡辐射供暖，门开着则全量输出——一扇门两种窗口。

🚪

对门直射，让屋子更亮

浴霸挂在与玻璃门正对的墙面，让约三成光直接穿门而出、其余靠镜面补射。相比"全反射出光"，地堡平均照度从 110~220 lux 提升到 250~330 lux，门口形成一道"阳光柱"。

🌞

烘干 = 对抗杭州的阴冷潮湿

红外辐射直接加热物体 → 空气升温使相对湿度骤降 → 强制排湿带走水汽。一台浴霸就是一台"晒太阳烘干机"，衣物、墙面、家具都能烘干，还顺带防霉防潮。

MATERIAL SYSTEM

材料系统 · 五件套

每件材料都服务于"多反射、少吸光、耐湿、安全"四个目标。

镜面不锈钢马赛克

6 面共 16.7㎡（含地面）。选 8K/超精镜面级（R 0.9+），细浅色勾缝把有效反射率推到 0.75~0.85；地面可选拉丝防滑镜面款。约 200~350 元/㎡。

超白钢化玻璃门

12mm 高透，可见光透射≈90%、近红外≈75%。既是灯箱出光口又是红外热窗。约 2,000~3,500 元/樘（含五金安装）。

不锈钢蹲便器

304 镜面抛光，反射不吸光，消除卫生间最后一块"暗吸收体"。选带防臭水封/冲水款。约 150~600 元/套。

壁挂 1000W 灯暖浴霸

4×275W 卤素，带漏保，壁挂于玻璃门对墙。≈19,000 lm 光 + 900W 热。约 300~500 元/台。

配套：排风扇（300~750 元）、防水基层（1,000~2,500 元）、独立电气回路 + 漏保（500~1,000 元）、双档/定时/联锁控制（200~800 元）。

WATER SYSTEM

水系统 · 空气雨淋 + 软水 + 华为智联热水

新增四件套：让淋浴成为"热带雨林"的空气花洒、让镜面永不结垢的软水系统、能用华为智慧生活 App 预热的电热水器，以及把蹲便"隐身"的镜面盖板。

冬季清晨 · 六面镜里的"私人热带雨林"（AI 生成示意）：空气花洒洒下温水幕，蒸汽蒸腾，暖金光弥漫。
🌧️

空气花洒 · 热带雨林淋雨

25~30cm 大顶喷 + 空气注入技术：水滴中掺入空气，颗粒更大更软、落体更密，覆盖全身，还原"热带阵雨"的包裹感。软水 + 空气注入双管齐下，水流温润不刺痛。

💧

软水系统 · 镜面永不结垢

离子交换软水机去除 Ca²⁺/Mg²⁺：不锈钢马赛克与玻璃门不再留水垢白斑，镜面长期锃亮，皮肤发丝也更顺滑。软水机体积较大，建议装在卫生间外的地堡内，只把软水管引入卫生间。

🔥

华为智联电热水器 · 醒来即太阳

60L 储水式电热水器（支持鸿蒙智联 / 智慧生活 App）：晨起前自动预热，进入卫生间即有 40°C 热水；可与浴霸做成"晨浴场景"一键联动。

🪞

镜面盖板 · 盖上就是全镜地面

不锈钢蹲便上方加一块 304 镜面承重盖板（≥150kg）：盖平时与地面齐平，卫生间最后一块"暗区"消失，整个地面是一面完整大镜子，灯箱的无限镜彻底闭合；使用时翻起，防臭水封照常。

💡 水系统闭环：软水 → 无垢 → 镜面长期锃亮 → 灯箱出光效率不掉；华为 App"晨浴场景"= 自动预热热水 + 打开浴霸光暖 + 排风联动，进门即"醒来见太阳"。
ENERGY · HEAT & DRY

全屋供能 · 光 + 热 + 烘干

当门打开，浴霸同时向整个地堡供光、供热、供烘干能力——这是方案在杭州冬季最值钱的部分。

🔥

1000W = 900W 热，门开全量供给

900W 热 + 100W 光在门开时全部进入地堡。对 30㎡、绝热良好的密闭空间，冬季（杭州 0~8°C）约可维持室内较室外高 8~15°C，覆盖约 1/3~1/2 采暖负荷——一个卫生间就是半个暖气。

🪟

关着门，也在供热

高透玻璃对近红外（0.8~2.5μm）透射 70~85%，卤素灯 900W 热中约 500W 能穿透玻璃辐射进地堡。所以即使门关，卫生间也在持续"烤暖"整座地堡。

🌡️

烘干三步 · 对抗阴冷潮湿

① 红外辐射直接加热衣物/物体表面加速蒸发；② 空气升温使相对湿度骤降（例：10°C/85%RH 加热到 20°C，RH 降到约 45%）；③ 热空气对流带走水汽。一台浴霸 = 一台"晒太阳烘干机"。

💨

排湿闭环 · 否则会变桑拿

密闭空间蒸发的水汽会重新推高绝对湿度、让烘干"卡住"。必须配：排气扇联动（开灯必排湿）+ 除湿机（杭州冬季 12L/天款约 800~1,500 元）。这样才是完整闭环，顺带解决无窗地堡的返潮、结露与防霉。

⚠️ 务必注意：900W 热若在"门关 + 无排风"的密闭 2㎡ 空间里运行，理论升温可达约 9°C/分钟，几分钟即成烤箱。因此安全上必须：开灯必开排风（联锁）、定时断电（30~60 分钟）、门开时才作全屋供能。
WINTER MORNING · EXPERIENCE

🌡️

温度体感 · 湿冷变湿热

40°C 水 + 900W 红外直接照肤 + 升温降湿：杭州湿冷冬天体感等效温度常比实际再低几度，而浴室里是"光热双供热"，湿身也不冷——红外补热恰好抵消了蒸发带走的热量，这是冬天洗澡不发抖的关键。

💡

光线氛围 · 你自己的太阳

19,000 lm 暖金光（2700~3000K）+ 六面无限镜：不是"开灯洗澡"，而是"走进一颗太阳"。明亮温暖的光在无窗地下空间里是强唤醒信号，冬晨的困倦被光冲走，还顺带缓解季节性情绪低落。

🫧

触感 · 软水 + 空气雨淋

软水让沐浴露起泡更丰富、冲得干净，皮肤不紧绷、镜面无水垢白斑；空气注入的雨淋水珠大而软，落在身上像被温热的大雨包裹，而非细针扎。

🧘

③ 三条生理通路（为什么这样有效）

👁️

光通路 · 视网膜 → 生物钟

强光激活视网膜视黑素细胞（ipRGC，峰值≈480nm）→ 下丘脑视交叉上核 SCN → ①抑制松果体褪黑素（睡意消退）；②启动 12-14 小时"白天计时器"（当晚更好睡）；③经唤醒中枢（蓝斑/丘脑）直接提升警觉。晨间强光还能前移皮质醇、体温、褪黑素的昼夜节律——正是冬季忧郁（SAD）患者体内缺失的那一步。

🧠

神经递质通路 · 情绪与动力

光照促进中缝核合成血清素——冬季光照不足导致血清素不足，是季节性情绪低落的核心机制之一；视黑素通路还驱动纹状体多巴胺释放（动机、专注）。"快乐递质"上来了，人自然醒来、有劲、不emo。

🌡️

温度通路 · 体温是"开机键"

38-40°C 热水 + 900W 红外使核心体温上升 0.2-0.5°C，模拟身体自然晨间体温爬升（睡眠→清醒的生物信号）；红外直接照肤抵消湿身蒸发散热——"湿着也不冷"正是这套方案的生理优势。注意：水温勿超 41°C、时长勿超 15-20 分钟，否则会转向副交感镇静（反而犯困）。

① 完整晨浴序列（含 30s 冷水收尾）

日出 · 0-2min

浴霸 2700-3000K 暖光爬升，眼平照度到 ≈9,500 lux；水温 38-40°C 预热，排风扇高档待命。

日照高峰 · 2-12min

全功率空气雨淋 + 900W 红外侧射；5000K 唤醒档逐步点亮（模拟日出→正午）；排风扇高档排雾，镜面不起雾。

冷水收尾 · 12-13min

恒温混水阀 30s 内把水温 40°C → ≈20°C；先冲四肢→后背→躯干，最后才到胸口，不冲头；激活交感神经，提神收尾。

出浴 · 13min+

排风扇转低档 3-5min 清余雾；浴霸保持 2-3min，在暖光中擦干、缓慢降温，避免"冷出浴"。

💡 冷水收尾设计要点：冬季自来水可低至 5-10°C，直接冲太刺激——恒温阀混到 ≈20°C（"凉爽"而非"刺骨"）；只冲四肢与后背、最后才到胸口，避免冷休克/血压骤变；心脑血管疾病、低血压、体弱者慎用或跳过；每周渐进适应（首周 20°C/15s → 逐步到 15°C/30s）。生理红利：去甲肾上腺素 + 多巴胺释放 → 警觉、情绪、抗炎、基础代谢提升。

BUILD GUIDE

施工指南 · 自己动手

防水与基层

墙面、地面做防水层（湿区重点），找平放线，确认门洞尺寸与排水坡度。若地下空间，同步预埋污水提升泵。

六面马赛克铺贴

先墙后顶再地；镜面马赛克用专用胶泥，缝宽 ≤2mm、浅色细勾缝；阴阳角做圆滑收口，避免尖锐反光伤人。

玻璃门安装

12mm 超白钢化玻璃门 + 不锈钢框体，确认朝地堡主区开向；如需隐私，同步装调光膜/内百叶。

浴霸对位

壁挂于玻璃门正对墙面、挂高、灯口朝门略下压；接独立回路 + 漏保 + 双档开关 + 门磁联锁。

排风与联锁

顶装排风扇并联动浴霸（开灯必排）；设 30~60 分钟定时；装防水开关面板。

验收点亮

低档试运行 → 检查温升、眩光、排风；再全开验证"光柱穿门"效果与地堡照度；贴上"勿直视灯源"提示。

// 晨浴模式 · 状态机核心框架（可映射到华为自动化或 Home Assistant）
enum State { IDLE, PREHEAT, SUNRISE, PEAK, COLD_FINISH, DRYING, DAY, NIGHT, SLEEP }

class MorningMode {
  state = State.IDLE;
  timer = null;

  onEnter(personPresent, humidity, time) {
    if (time === "06:20" && !personPresent) this.start(State.PREHEAT);
    else if (personPresent && hour in [6, 7]) this.start(State.SUNRISE);
    else if (humidity > 70) fan.set(3);      // 湿度联动排风
  }

  start(s) {
    this.state = s; this.run(s);
    this.timer = setTimeout(() => this.next(s), DURATION[s]);
  }

  run(s) {
    switch(s) {
      case State.SUNRISE:   yuba.power(100); light.cct(2700); break;
      case State.PEAK:       light.rampCCT(2700, 5000, 600000); shower.on(40); break;
      case State.COLD_FINISH: valve.setTemp(20); voice.say("30秒冷水收尾"); break;
      case State.DRYING:     fan.set(1); yuba.keep(180000); break;
    }
  }

  next(s) { // 状态迁移：时间驱动 + 条件守卫
    const guards = {
      SUNRISE:     () => State.PEAK,
      PEAK:        () => person.present ? State.COLD_FINISH : State.DRYING,
      COLD_FINISH: () => State.DRYING,
      DRYING:      () => humidity < 55 ? State.DAY : State.DRYING,
    };
    this.start(guards[s]());
  }
}
