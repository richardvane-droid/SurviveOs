# inbox — 手机随手记的任务单

在手机上想到什么就往这里丢一个文件,格式不限:一句话、一张清单、一段语音转文字都行。
不需要编号、不需要套模板、不需要挑目录,想清楚再整理是下一步的事。

## 怎么用

1. 手机上新建一个文件扔进 `inbox/`,文件名随便起(建议带日期,例如 `2026-09-15-草地管网重做.md`)
2. 下次开 Cowork/Claude Code 会话时说"处理一下 inbox",让它读这里的任务单
3. 处理完的任务单**删掉**,或者移到 `outputs/` 留痕

## 边界

- 这里的内容是草稿,不是权威文档。正式结论要落到对应区域的模块文档里。
- 不要往这里放密钥、证件、财务信息(见根目录 CLAUDE.md 的「边界」)。
- 二进制素材(照片/PDF/截图)不进这里,进 Google Drive 的 `SurviveOs-素材/`。
