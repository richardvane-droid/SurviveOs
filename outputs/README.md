# outputs — agent 产出的落地区

agent(Cowork 会话、Claude Code、定时任务)生成的东西先落在这里,等你 review 过,
再并入对应区域的正式模块文档。没 review 的产出不算数,别直接当权威版本引用。

## 怎么用

1. agent 把产出写成文件放这里,文件名建议 `<四位编号>-<说明>.md`,例如 `0203-控温控湿-方案初稿.md`
2. 你在手机上翻一遍,确认没跑偏
3. 确认后由会话把内容并进 `02-地堡/0203-控温控湿.md` 之类的正式文档,再把这里的中间产物删掉

## 边界

- 这里是中转区,不是归档区。长期留在这里的文件说明流程卡住了,该处理掉。
- 正式模块文档的结构、素材段格式见根目录 CLAUDE.md。
