01

项目背景与目标

GOAL

结论先行：这是一套「只在地里说话」的灌溉系统——滴灌管埋在地下 10cm、阀与控制器装进密封阀箱，地表只剩草和树；用水逻辑完全交给传感器，人只需要在华为智慧生活 App 里看着、偶尔远程点一下。

核心目标

  • 稀树草原美学不被任何水管/喷头破坏
  • 建成后零人工浇灌，全部自动
  • 设备总成本 ≤ 5000 元，全部 DIY

硬性约束

  • 控制器必须对接华为智慧生活 App
  • 灌溉方式：地埋滴灌（全隐藏）
  • 加入雨水收集，预算可适当放宽

已有条件

  • 疏林树木已栽好（成本不计入）
  • 自己动手施工、自己折腾调试
  • 北京气候（冬季需防冻泄水）
一条贯穿始终的原则：稀树草原 = 低耗水、深根系、旱养。系统不是"天天浇水"，而是"只在土壤真的缺水时精确补水，一次浇透促根深扎"。传感器不是噱头，它正是省水省钱的核心。
02

设计理念：全隐藏 + 按需补水

PHILOSOPHY

把"看不见"做到极致：管网、滴头、阀、控制器、传感器全部埋入地下或收进阀箱；把"自动化"做到极致：人只负责设定和偶尔查看，浇不浇、浇多少由土壤和天气决定。

为什么选地埋滴灌（SDI）而不是喷灌

喷灌要把喷头露出地面或弹出，既破坏草原视觉，蒸发损失也大（约 30%）。地埋滴灌把 16mm 滴灌管埋在草根层下方 10cm，水直接从根系层渗出：

  • 隐形：地表零设备，完工后只看见草和树
  • 省水：灌溉效率约 90%+，比喷灌节水 30%+
  • 防病：不浇叶面，草坪病害少
  • 树草分离：树下单独滴灌，树干不积水

为什么传感器必须参与决策

稀树草原草皮"旱养"的特性，决定了它不需要固定周期灌溉，需要的是"土壤含水量低于阈值才补"。

  • 土壤湿度传感器（电容式）埋入根系层，是浇水的"唯一裁判"
  • 雨量传感器 + 天气，雨天自动停
  • 水位传感器管雨水/自来水切换
  • 三路传感器 → 本地 ESP32 逻辑 → 硬切断电磁阀
03

系统总体架构

ARCHITECTURE

三层结构：水源层（雨水优先/自来水补位）→ 控制层（华为 App 遥控 + ESP32 湿度许可，双钥匙串联）→ 管网层（地下滴灌网络）。

双钥匙的含义：钥匙①（华为 App 控制的鸿蒙水阀/智能开关）决定"要不要浇这个区"；钥匙②（ESP32 + 湿度/雨量判断）决定"现在土壤需不需要水"。两把钥匙串联，任何一把断开都不出水——App 设了浇水计划，但湿度够高或在下雨，系统自动停手。

04

分区与植物（树已栽，只补草与点缀）

ZONES

稀树草原 = 疏林（已有的树）＋ 大片耐旱草 ＋ 少量观赏草/花点缀。浇水按"植物需水"分三档，绝不一刀切。

分区面积/数量植物配置灌溉方式建成后需水
A 草坪区约 35㎡野牛草（极耐旱、夏眠金黄、原生草原感）或 结缕草/高羊茅耐旱混播地埋滴灌管 16mm，间距 40cm，埋深 10cm旱季约 4~6mm/周（一次浇透）
B 树木区2~3 棵（已栽）白皮松/蒙古栎/皂角等疏林树每树 4 个滴箭/涌泉头，沿树冠滴水线建成后基本靠天，仅持续干旱时补
C 点缀带约 8㎡狼尾草、细叶芒等观赏草 + 松果菊/鼠尾草微滴灌（可选），观赏草本身极耐旱极低，可旱养
设计巧思：滴灌管全部埋在地下 10cm 的草根层下方，地表零设备；喷头、阀箱、控制器统一收进地埋阀箱，完工后这个院子"看起来"就是纯粹的草原，没有任何灌溉痕迹。
05

地埋滴灌设计（SDI）

SUBSURFACE DRIP

草坪地埋滴灌的关键参数：压力补偿（PC）滴灌管、120 目精滤、滴头间距 30cm、管距 40cm、埋深 10cm——保证湿润锋相互搭接、草皮均匀受水。

选型规格（对标成熟产品参数）

项目规格说明
滴灌管16mm 内镶压力补偿（PC）滴灌管滴头 2.3L/h、间距 30cm，压力补偿保证整条管出水均匀
主管PE 20mm从阀箱到各分区的输水干管，埋深 30~40cm
过滤120 目叠片/网式过滤器地埋滴灌的硬性要求，防止滴头堵塞（必须加）
排水支管末端排水阀 + 管路坡度冬季泄水防冻裂（北京必做）

参数参考：雨鸟 XFS 地埋滴灌系列（16mm / 滴头 2.3、3.5 L/h / 间距 30、45.7、61cm / 过滤 120 目），草坪 SDI 埋深 10~15cm 为行业通行做法。

06

华为智慧生活对接 + 自动化逻辑

HUAWEI & AUTOMATION

把"人机界面"和"智能决策"分层：华为智慧生活 App 负责遥控、定时、场景；本地 ESP32 负责土壤湿度/雨量/水位的硬判断。两层各管各的，任一失效都安全。

① 华为智慧生活 App 层（钥匙①）

硬件选型（二选一）

  • 方案甲 · 鸿蒙智联智能水阀（电动球阀，直接装在分区水管上，App 原生控制，约 210~300 元/个）——更直接、可看阀门状态
  • 方案乙 · 鸿蒙智联智能插座（控制 24VAC 变压器给电磁阀供电，约 60~90 元/个）——更便宜、生态产品多

App 里能做什么

  • 手动远程开/关分区
  • 定时计划（自动场景：每天凌晨 4:00 开、5:00 关）
  • 小艺语音："小艺小艺，给草坪浇 20 分钟"
  • 全屋场景联动（可并入家中其他智能设备）

② 本地 DIY 感知层（钥匙②，ESP32）

传感器数量布点作用
电容式土壤湿度传感器4草坪 2 个 + 树下 1 个 + 花境 1 个（埋 10~15cm）含水量 <25% 才放水，≥40% 停（"少次多量"促深根）
雨量传感器（翻斗式）1阀箱附近下雨强制跳过本次浇水
水位开关/浮球1~2雨水罐内低水位 → 自动切入自来水补位

串联逻辑（硬切断，安全优先）：ESP32 读全部传感器 → 判断"本次是否允许浇水" → 通过继电器串接在供水主电磁阀回路。湿度够/在下雨 → 继电器断开 → 即使 App 开了分区也没水；湿度低且非雨 → 继电器闭合 → App 定时窗口一到就浇。

关于"生态边界"的实话：华为智慧生活 App 原生生态里，土壤湿度类传感器很少（多为空气温湿度）。所以本方案让 App 管开关/定时/语音，湿度闭环走本地 ESP32——这是目前"华为 App + 湿度自动化"最可靠、最便宜的组合。若你后期想在一个 App 里看湿度曲线，可给 ESP32 加一块小屏或本地网页，数据不出局域网，不影响华为侧使用。
07

雨水收集设计

RAINWATER

雨水优先、自来水补位。北京年降雨约 550~600mm，一小块屋面就能灌满罐子；关键设计是"首雨弃流 + 自动切自来水"，保证滴头不被脏水堵、旱季也不断水。

雨水收集流程

屋面/硬化面雨落管 → 首雨弃流器（把污染的前 1~2mm 雨水排掉）→ 滤网 → 800~1000L PE 储水罐 → 自吸泵 → 主管。

储罐容量 800~1000L（50~100㎡ 庭院通行的地上/埋地规格）。

缺水自动补位

罐内水位开关检测：水位低于下限 → ESP32 打开自来水补位电磁阀；水位恢复 → 关闭。全程自动，无需人工干预。

水账项目估算口径
建成后需水约 140~250 L/周耐旱草皮 35㎡ × 4~6mm/周；树基本靠天
夏季最长无雨期1~2 周（北京）罐 800~1000L ≈ 可撑 3~4 周，安全
年集雨潜力20㎡ 屋面 ≈ 6000~11000 L/年550~600mm 年降雨 × 屋面 × 有效系数
自来水角色仅补位连雨天几乎用不到；旱季偶尔补

雨水必须先过滤再进滴灌（120 目），否则滴头堵塞是地埋系统第一大杀手；储罐需配溢流口和防蚊盖。

施工步骤（自己动手）

BUILD

按"放线 → 挖沟 → 铺管 → 装阀 → 接线 → 试压 → 覆土铺草 → 调试 → 入冬泄水"顺序推进，50㎡ 约 2~3 天集中施工 + 2 周建立期调参。

第 1 步 · 放线分区

在院子里标出草坪区、树木区、点缀带；画出主管和滴灌管走向（主管 30~40cm 深，滴灌管 10cm 深，带坡度向排水阀）。

第 2 步 · 挖沟铺管

用开沟器/铁锹挖沟；先铺主管，再铺 16mm 滴灌管（迷宫纹朝上），树下布滴箭；避免锐弯、石子压管。

第 3 步 · 装阀与滤器

阀箱内装：叠片过滤器 → 主切断电磁阀 → 分区分水管（接鸿蒙智能水阀）。所有接头用生料带/卡箍密封，试压查漏。

第 4 步 · 接线与传感器

拉 24V 控制线 + 电源线进阀箱；ESP32 接 4 路湿度传感器（埋 10~15cm）+ 雨量 + 水位；全部防水接线，入密封箱。

第 5 步 · 华为 App 配置

鸿蒙水阀配网进智慧生活 App → 建"定时场景"（凌晨窗口）→ 绑定小艺语音；ESP32 设湿度阈值（草坪 25%/40%）。

第 6 步 · 覆土铺草 + 建立期

回填压实、铺耐旱草皮。前 2~3 个月是"建立期"：系统勤补水促扎根，之后切到旱养模式（湿度阈值制）。

第 7 步 · 入冬泄水（北京必做）

11 月前：打开各支管排水阀 + 主管放水，拆下易冻件，确保管内无水；春季回装、试压、重新校准阈值。

待你拍板的决策点

DECISIONS

D1 · 智能水阀选"方案甲还是乙"？

甲：鸿蒙智联电动球阀直控分区（约 260 元/个，看得到阀门状态）；乙：鸿蒙智能插座 + 电磁阀（约便宜 1/3，只看到开关）。预算内我建议甲，可靠性更高。

D2 · 储水罐 800L 还是 1000L？

1000L 约 +150~250 元，夏天无雨期可多撑 1 周多。若屋面无大集水面，800L 够；若想更省自来水，上 1000L。

D3 · 草坪草种确认？

要"草原金黄感"选野牛草（夏眠变黄，最省水）；要"四季常绿"选结缕草/高羊茅混播。这决定灌溉阈值和视觉风格。

D4 · 是否保留"观赏草点缀带"浇水？

观赏草本身极耐旱，建议并入旱养不浇（省一个分区和阀门钱）；若要养花（松果菊等）则需一个微滴灌分区。
