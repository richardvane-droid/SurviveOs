THREE ZONES

三分区，三种需水

灌溉按植物需水分三档：草坪、树木、点缀带各浇各的，绝不一刀切。已按你的选择——观赏效果优先的草种、点缀带浇水为未来养花打底。

每周 1 次 · 浇透

草坪区 · 35㎡

16mm 地埋滴灌管，管距 40cm、滴头 30cm，水从根系层直接渗出。观赏型耐旱混播草皮，旱季每周一次浇透促根深扎。

高羊茅耐旱混播 · 绿期长、观赏性好
靠天为主 · 偶补

树木区 · 2~3 棵（已栽）

每树 4 个滴箭/涌泉头，沿树冠滴水线环形补水。大树建成后根系深，基本靠天，仅持续干旱时补一点。

树已栽好 · 成本不计入
预留待用 · 现旱养

点缀带 · 8㎡

观赏草丛现在旱养不浇；预埋微滴灌管，等你想在局部养花时，随时接入新分区即可，不用再动土。

WHY THIS PROJECT

为什么这样设计

双钥匙控制 · 手机「想不想浇」＋ 单片机「该不该浇」，任一断开都不出水
🌿

稀树草原，就该旱养

低耗水、深根系是草原的本性。这套系统不做"天天浇水"，只在土壤含水量低于阈值时精确补水、一次浇透——水费、电费、人工都省到最低，草还越长越耐旱。

🔑

双钥匙控制，不会乱浇

华为智慧生活 App 管"想不想浇"（遥控 / 定时 / 场景 / 小艺），ESP32 管"该不该浇"（湿度 / 雨量 / 水位）。两把钥匙串联，任一断开都不出水——App 开了计划，土壤够湿或在下雨，系统自动停手。

💧

雨水优先，自来水兜底

1000L 雨水罐 + 首雨弃流，连雨期几乎零水费；罐空自动切自来水补位，全程无人值守。地下管网 + 密封阀箱，地表零设备，草原视觉一点不被破坏。

施工指南 · 自己动手

按"放线 → 挖沟 → 铺管 → 装阀 → 接线 → 试压 → 覆土铺草 → 调试 → 入冬泄水"推进，50㎡ 约 2~3 天集中施工 + 2 周建立期调参。

施工流程一览 · 放线 → 挖沟 → 铺管 → 装阀 → 覆土铺草（示意海报）
放线分区

标出草坪 / 树木 / 点缀带，画主管与滴灌管走向（主管 30~40cm 深，滴灌管 10cm 深，带坡度向排水阀）。

挖沟铺管

先铺 PE 主管，再铺 16mm 滴灌管（迷宫纹朝上），树下布滴箭；避免锐弯、石子压管。

装阀与滤器

阀箱内装：120 目过滤器 → 主切断电磁阀 → 分区分水管接鸿蒙智能水阀。所有接头密封，试压查漏。

接线与传感器

拉 24V 控制线 + 电源线进阀箱；ESP32 接 4 路湿度传感器（埋 10~15cm）+ 雨量 + 水位，全部防水入密封箱。

华为 App 配置

鸿蒙水阀配网进智慧生活 App → 建定时场景（凌晨窗口）→ 绑定小艺语音；ESP32 设湿度阈值（草坪 25% / 40%）。

覆土铺草 + 建立期

回填压实、铺耐旱草皮。前 2~3 个月勤补水促扎根，之后切到旱养模式。

入冬泄水（北京必做）

11 月前：打开各支管排水阀 + 主管放水，拆下易冻件；春季回装、试压、重新校准阈值。

华为智慧生活 App 配置步骤

  • 配网：鸿蒙智联智能水阀通电进入配网态 → 打开智慧生活 App → 右上角"+"添加设备 → 扫码/搜索添加。
  • 定时场景：首页家居 → 智慧场景 → 新建自动场景 → 触发条件选"每天 04:00" → 执行任务选"打开草坪区水阀 60 分钟"。
  • 小艺语音：在 App 里启用语音控制后，对小艺说"给草坪浇 20 分钟"即可手动补水。
  • 双水源切换：ESP32 读罐内水位，低水位自动打开自来水补位电磁阀；水位恢复即关。全程无需在 App 操作。
💡 生态边界说明：华为智慧生活 App 原生生态里的土壤湿度传感器很少，所以湿度闭环放本地 ESP32（第二把钥匙），App 负责开关 / 定时 / 场景 / 语音。这是目前"华为 App + 湿度自动化"最可靠、最便宜的组合。
