THREE ZONES

三分区，三种需水

灌溉按植物需水分三档：草坪、树木、点缀带各浇各的，绝不一刀切。已按你的选择——观赏效果优先的草种、点缀带浇水为未来养花打底。

雨养为主 · 晴热期补水

草坪区 · 35㎡

16mm 地埋滴灌管，管距 40cm、滴头 30cm，水从根系层直接渗出。杭州雨多，草坪以“靠天 + 湿度兜底”为主，仅晴热少雨季补水；水肥一体时顺便补肥。

高羊茅耐旱混播 · 绿期长、观赏性好
靠天为主 · 偶补

树木区 · 2~3 棵（已栽）

每树 4 个滴箭/涌泉头，沿树冠滴水线环形补水。大树建成后根系深，基本靠天，仅持续干旱时补一点。

树已栽好 · 成本不计入
预留待用 · 现旱养

点缀带 · 8㎡

观赏草丛现在旱养不浇；预埋微滴灌管，等你想在局部养花时，随时接入新分区、接上施肥支路，不用再动土。

FERTIGATION

水肥一体化 · 浇水即施肥

在主管道上旁通一个文丘里施肥器，配一只施肥桶：水流经过时产生的负压自动把肥液吸进水里——浇水的同时就把肥喂了，一次完成、全自动调配。

文丘里施肥器原理 · 水流喉部负压吸肥，无需电力（示意海报）

全链路

施肥桶 → 文丘里 → 主管道合流 → 滴灌管 → 草根：水和养分一起走地下，地表无痕。

施肥桶

20~50L 桶装水溶肥，文丘里从这里吸肥；薄肥勤施，肥液浓度自己调。

水肥同步

滴头同时渗出水和养分到根系层，肥随水走、不淋叶面，吸收率更高、病害更少。

自动化调配

ESP32 在“该施肥”时打开施肥电磁阀几分钟，肥液随浇水一起进土；华为 App 一键触发“施肥场景”。

💡 施肥策略（杭州）：生长期每 2~3 周一次薄肥（平衡型水溶肥，比例约 1:1000），随浇水进行；梅雨季湿度大，减少施肥防徒长与病害；施肥后用清水冲灌 5 分钟，冲净管路残留。想更省事的平替 = 手动往施肥桶倒一次肥，系统照常自动浇。
WEATHER TRIGGER

天气联动 · 彩云预报当第四把钥匙

接入彩云天气的分钟级降水预报（未来 2 小时逐分钟降水、1 公里精度，个人开发者有免费额度）：云层什么时候到、会下多久，系统提前就知道——集雨网该开就开，浇水该停就停。天气数据从此成为触发条件之一。

彩云天气降雨预报 → 集雨网张开 / 浇水暂停（示意海报）
🛰️

预报源

彩云天气开放平台，实况准确率约 95%、分钟级降水预报 91%；分钟级数据未来 2 小时逐分钟降水强度，1km 级精度，正好覆盖一个院子。

⚙️

触发规则

主机/ESP32 每 5~10 分钟轮询一次：未来 1~2 小时内有持续降雨（降水强度超阈值且持续 15 分钟以上）→ 张开集雨网 + 跳过/延后浇水；本地翻斗雨量计实测降雨做兜底，预报失灵也不漏。

🎛️

对浇水决策的影响

预报有雨 → 今天不浇（省水省电）；预报连晴 → 恢复正常按湿度浇水；台风预警 → 集雨网收起 + 排水系统待命。四把钥匙：App、湿度、长势、天气，全部满足才浇。

AUTO RAIN COLLECTOR

自动开合集雨网 · 云层到了就张开

一个能自动开合的大网面装置，像网球网那样在庭院上方撑开接雨，雨停就自动折叠收好。展开时约 12㎡ 集雨面，杭州一年能多收约 1 万升雨水——和屋顶雨水合在一起，让 1000L 罐在雨季常满、旱季有备。

集雨面导流 → 储水罐 · 一片网就是一片小屋顶（效果示意）
🕸️

它是什么

一卷防水涂层网面装在顶部卷轴上，由线性推杆/卷绕电机驱动：张开时呈 30° 倾斜的集雨面，雨水沿网面流到低缘导流槽 → 管道 → 储水罐；收拢时叠成小卷藏进侧边立柱，防风防尘。

⚙️

怎么自动开合

ESP32/主机按彩云预报判断：预报 1~2h 内有持续雨 → 电机正转展开；雨停 + 预报转晴 → 电机反转折叠。限位开关定开/合两端，断电记忆位置；本地雨量计兜底触发。

💧

集雨量与收益

12㎡ × 杭州 1450mm 年降雨 ≈ 理论 17,000L/年，按有效系数约 1 万升——相当于让雨水收集量直接翻倍，罐更常满、自来水更少用。

💡 诚实提醒：这是 DIY 装置，网上没有成品卖。网面用防水涂层布或 90% 遮阳网 + PVC 涂层面料；结构参照“电动卷帘 / 折叠雨棚”原理自组，预算约 500 元。台风预警联动收起是必做的保护逻辑。

📷

摄像头 = 眼睛

华为智选室外摄像头接入华为智慧生活 App，实时画面随时看；系统每天 1~2 次自动截一张草坪全景图，交给云端分析。

☁️

云端大模型 = 大脑

截图上传视觉大模型 API，返回结构化诊断：草色指数（绿 / 黄 / 枯占比）、覆盖度、枯黄原因判断（缺水 / 缺肥 / 病害 / 正常休眠），以及建议动作（浇水 / 施肥 / 修剪 / 打孔透气）。

🎛️

联动闭环

诊断结果写回决策：缺肥 → 触发施肥场景；缺水 → 补水；过湿 / 病害 → 停水停肥并提示排水；夏季休眠泛黄 → 只保命不施肥。长势好 → 自动降低浇水施肥频次。

💡 成本与边界：视觉大模型按次计费，每天 2 次 × 每月 60 次，全年约 200 元内（多数平台免费额度够用）。华为生态仍不做这类分析，所以走“摄像头取图 → 云端 API 分析 → 结果回本地 ESP32 决策”，华为 App 管场景与展示。最省事的平替 = 打开手机看画面 + 人工点一次施肥。
CANOPY & SUNLIGHT

树冠日照 · 阴影多了就该剪枝

摄像头不只盯着草，也盯着树：云端分析树冠大小与生长趋势，结合太阳位置算出每块草皮的实际日照时长。一旦树荫把草皮的光抢走太多，系统会给出明确的剪枝建议——这是“全年视觉”里最容易被忽略的一环。

树冠 + 日照热力图分析 · 摄像头画面 → 树冠分割 → 草皮日照时长分布（示意海报）
🌳

树冠监测

云端大模型在画面中分割树冠区域，估算冠幅与枝叶密度；随时间对比算出冠幅增长率，判断树是不是正在“越长越遮”。金合欢类稀树草原树冠偏开散，正是监控重点。

☀️

日照时长分析

结合日期 + 经纬度算太阳轨迹，把树冠阴影映射到草坪分区，算出每块草皮日累计直射日照（小时）。杭州年日照约 1700h、春秋多云雾，冷季型草需要日直射光 ≥4~6h。

✂️

剪枝逻辑

某分区日照连续 2~3 周低于下限、且树冠仍在扩大 → 系统生成“剪枝任务”：提示树冠方向、覆盖比例、建议回缩主枝 1~1.5m。剪枝由人工执行，系统只监测、提醒、看趋势。

草皮分区日照判定日直射光系统动作
充足≥ 6 小时正常管理
临界4~6 小时观察趋势，减少该区施肥
不足（树荫遮蔽）< 4 小时触发剪枝建议 + 该区改耐阴草 / 减少耗水管理
过量（夏季暴晒）夏季全日照无遮挡高温期提示保水 / 留高遮阴
💡 落地口径：日照分析是云端大模型的扩展能力（同一次视觉分析返回冠幅 + 阴影覆盖），不新增硬件；“剪枝”仍由你或园丁动手，系统负责在 7 寸屏和华为 App 里给出清晰的任务卡与趋势曲线。

施工指南 · 自己动手（杭州版）

按"放线 → 挖沟 → 铺管 → 装阀 → 加装施肥支路 → 做排水 → 装集雨网 → 接线 → 试压 → 覆土铺草 → 调试 → 入冬泄水"推进，50㎡ 约 3~4 天集中施工 + 2 周建立期调参。

施工流程一览 · 放线 → 挖沟 → 铺管 → 装阀 → 覆土铺草（示意海报）
放线分区

标出草坪 / 树木 / 点缀带，画主管与滴灌管走向（主管 30~40cm 深，滴灌管 10cm 深，带坡度向排水阀）。杭州多雨，同步规划好排水方向与溢流去路。

挖沟铺管

先铺 PE 主管，再铺 16mm 滴灌管（迷宫纹朝上），树下布滴箭；避免锐弯、石子压管。梅雨季前完工，避开连雨期施工。

装阀与滤器

阀箱内装：120 目过滤器 → 主切断电磁阀 → 分区分水管接鸿蒙智能水阀。所有接头密封，试压查漏。

加装施肥支路（新增）

在过滤器之后旁通接文丘里施肥器：主管给水段 → 文丘里 → 回水段，吸肥管伸进施肥桶；施肥电磁阀串在文丘里吸肥回路，单向阀防肥液倒灌。置于阀箱或施肥小箱。

做排水（新增）

草坪区挖盲沟：铺土工布 → 填碎石 → 放 Φ50 透水管 → 坡度 1% 汇入渗水井；铺草前垫蓄排水板 / 沙砾层，防杭州雨季涝根。

装自动集雨网（新增）

立支架装卷轴 / 推杆 → 铺防水网面 → 低缘接导流槽进罐 → 接 ESP32 开合控制（限位开关定两端）；接彩云预报联动逻辑，台风预警强制收起。

接线与传感器

拉 24V 控制线 + 电源线进阀箱；ESP32 接 4 路湿度传感器（埋 10~15cm）+ 雨量 + 水位 + 施肥电磁阀控制，全部防水入密封箱。摄像头安装位置对好草坪视角、避开逆光。

华为 App 配置

鸿蒙水阀配网进智慧生活 App → 建三个场景（浇水定时场景、施肥触发场景、监控查看）→ 绑定小艺语音；ESP32 设湿度阈值（草坪 25% / 40%）+ 施肥时机。

长势分析调参（可选）

摄像头每天 1~2 次定时截图上传云端视觉大模型，返回草色 / 覆盖度 / 枯黄原因 / 建议动作；结果写回 ESP32，联动补水补肥。

装 7 寸屏 + 日照剪枝调参（新增）

挂 7 寸 IPS 屏，主机跑网页仪表盘（实时参数 + 曲线 + 季度延时）；云端分析扩展到树冠分割与分区日照热力图，标定“光照充足”基准，日照连续不足自动生成剪枝任务。

覆土铺草 + 建立期

回填压实、铺耐旱草皮。前 2~3 个月勤补水促扎根，之后切到旱养模式。

入冬泄水（杭州也要做）

杭州极端低温约 -1~-5°C，仍有冻裂风险：11 月底前打开各支管排水阀 + 主管放水、拆下易冻件与施肥支路；春季回装、试压、重新校准阈值。

💡 杭州特别提醒：梅雨季湿度大，草坪注意排水防涝、减少施肥防病害；8-9 月台风前加固摄像头与罐体；雨量传感器放开阔处别被树冠挡雨。

天气触发 · 彩云接入配置

  • 拿 Token：彩云开放平台注册 → 个人开发者认证 → 生成 API Token（有免费额度）→ 记下你庭院的经纬度。
  • 轮询：ESP32 / 主机每 5~10 分钟请求一次分钟级降水接口，读未来 1~2h 降水强度（1km 精度）。
  • 开合阈值：未来 1~2h 内降水强度 ≥ 中雨且持续 ≥15 分钟 → 张开集雨网、跳过浇水；雨停 + 预报转晴 → 折叠恢复；台风预警 → 强制收起集雨网、排水待命。本地翻斗雨量计实测兜底。

云端长势 · 摄像头分析配置

  • 取图：摄像头固定机位，每天 08:00 / 17:00 各截一张草坪全景。
  • 分析：截图上传视觉大模型 API，返回草色 / 覆盖度 / 枯黄原因 / 建议动作。
  • 联动：结果写回 ESP32：缺肥 → 触发施肥场景；缺水 → 补水；过湿 / 病害 → 停水停肥并提示排水；长势好 → 自动降频次。

排水 · 雨季泄水

  • 盲沟 + 透水管 + 渗水井把雨季土中水分排走；ESP32 读到湿度持续 >60% 且在下雨 → 判定过湿，暂停浇水并提示排水。
  • 台风暴雨预警：彩云预警联动 → 集雨网收起 + 排水待命；低洼积水点可加小排水泵强制排走。

7 寸屏 · 数据呈现配置

  • 主机汇总 ESP32 传感器 + 云端长势 / 日照结果 → 网页仪表盘（深色科技风：实时卡片 + 24h / 7d / 30d 曲线 + 环形仪表 + 季度“一帧/天”延时循环播放）。
  • 摄像头每天固定机位存 1 帧，一个季度约 90 帧自动拼成 3~6 秒延时视频；树冠分割 + 分区日照热力图 → 日照不足生成剪枝任务。控制仍全部走华为智慧生活 App，屏幕只读。

华为智慧生活 App 配置步骤（三个场景）

  • 浇水场景：首页家居 → 智慧场景 → 新建自动场景 → 触发条件"每天 05:00 或 湿度低于阈值" → 执行任务"打开草坪区水阀 40 分钟"。ESP32 侧再套湿度/雨量校验，双保险。
  • 施肥场景：新建场景"启动施肥" → 执行任务"打开施肥电磁阀 10 分钟 + 打开对应分区水阀"；可绑定小艺语音"给草坪施肥"、或在长势指数低时由本地触发。

杭州 6 月梅雨 + 8-9 月台风，土里水分过多会烂根黄叶。地下做盲沟 + 透水管 + 渗水井，把多余水排走；ESP32 读到土壤湿度过高就自动停水、提示排水。

冬季保绿 · 低温也不黄

杭州 1 月平均最低 1~4°C、极端 -5°C，选冷季型草（高羊茅 + 多年生黑麦草混播）基本能全年保持绿；冬季减水停肥、修剪留高保温，极端寒潮盖防冻布。

雨季排水 · 方案要点

  • 草坪区地下铺盲沟排水：碎石层 + Φ50 透水管 + 土工布，间距 3~5m、坡度 1%，汇入渗水井 / 排水检查井；杭州粘性土（红壤 / 水稻土）必须做，否则一下大雨就涝。
  • 铺草前垫蓄排水板或沙砾层，让根系层不泡水。
  • 智能泄水：ESP32 读湿度上限，持续 >60% 且在下雨 → 判定“过湿”，暂停浇水并提示；有积水点 → 可加小排水泵强制排走。
  • 地表做微坡，低洼处设雨水口，让水往盲沟走、不往草根里沤。

冬季保绿 · 方案要点

  • 草种：高羊茅（冷季型，耐 -15°C）+ 多年生黑麦草混播，杭州冬季能保持绿色，不像暖季型草会枯黄休眠。
  • 冬季管理：减少浇水（土温低、蒸腾小）、停止施肥（防嫩梢冻伤）、修剪留高 3~5cm 保温；11 月底完成泄水防冻裂。
  • 极端寒潮（预报 -3°C 以下）：给草坪覆盖防冻无纺布，白天揭开；彩云低温预警可联动提醒。

夏季控温 · 高温不枯

  • 杭州 7-8 月常 35~40°C，冷季型草可能“夏枯”变黄：清晨补水降温、停氮肥、修剪留高 5~7cm 遮阴。
  • 必要时混播少量耐热品种过渡；高温天系统按“保命不催长”策略自动降低施肥。

光照与剪枝 · 树荫别把草闷黄

  • 日照监测：摄像头画面 + 云端分析算出每块草皮日直射日照（小时），杭州年日照约 1700h、春秋多云，冷季型草需 ≥4~6h。
  • 树冠趋势：跟踪冠幅与覆盖率的季度变化，判断树是不是越长越遮。
  • 剪枝任务：某区日照连续 2~3 周低于下限且树冠在扩大 → 7 寸屏 / 华为 App 生成剪枝任务卡（方向 / 覆盖比例 / 回缩建议），由人工或园丁执行。

软件与程序 · 从传感器到水阀的代码路径

硬件是骨架，程序是神经。整套逻辑由四段程序协作完成：本地 ESP32 决策（读传感器 + 硬切断）、华为智慧生活 App 场景（想不想浇 / 定时 / 语音）、彩云天气轮询（下不下雨）、云端视觉分析（长势 / 树冠 / 日照）。下面按 6 张主流程图逐一拆解。

📡

程序分层

采集层（ESP32 每 30s 读湿度×4 / 雨量 / 水位）→ 决策层（四把钥匙逻辑，任一不满足就硬切断）→ 执行层（继电器驱动 电磁阀 / 电动球阀 / 泵 / 推杆）→ 数据层（MQTT / HTTP 上报主机）→ 呈现层（7 寸屏 + 华为 App）。

🧠

ESP32 固件职责

主循环：采集 → 本地校验 → 按场景执行 → 上报。它不抢华为 App 的活，只做“该不该出水”的最后一道物理闸门——App 开了计划、土壤够湿、在下雨、长势异常或预报有雨，都在这层被拦下。

流程图 1 · 主决策总流程（四把钥匙串联）

  • 触发源：每天定时（如 05:00）、湿度低于阈值、小艺语音“浇 20 分钟”、App 手动，都能发起一次流程。
  • 四把钥匙全过才出水：App 已授权 ∧ 土壤真的缺水 ∧ 此刻无雨且预报无雨 ∧ 长势需要水。任何一把钥匙不满足，系统直接跳过并记录原因——这就是“不会乱浇”的代码保证。
  • 双保险：App 层和 ESP32 层各校验一次；ESP32 是物理闸门，即使 App 出错也由它兜底。

流程图 2 · 浇水决策

  • 湿度是第一道闸：只有土壤真的缺水才考虑浇；杭州雨多，多数时候流程在这一步就结束。
  • 雨是第二道闸：本地雨量计 + 彩云预报双路，正在下雨或马上要下雨都停手。
  • 长势是第三道闸：云端说“过湿 / 有病害”时不但不浇，还会提示排水或处理。
  • 水源保障：低水位先自动开自来水补位阀，避免水泵空转。

流程图 3 · 施肥决策（浇水=施肥）

  • 时机：只在非雨天且土壤湿度适中时施肥——雨前施会被冲走，太干施容易烧根。
  • 稀释保护：施肥期间先开水阀再开施肥阀，肥液被水流稀释；结束后必须清水冲灌 5 分钟，防肥液残留在管内结晶堵滴头。
  • 薄肥勤施：低浓度多次，比一次浓肥安全；梅雨停肥、冬季停肥由季节策略自动控制。

流程图 4 · 集雨网开合

  • 预告才张开：靠彩云分钟级预报“提前知道要下雨”，网面张开接住第一波雨，一年多收上万升。
  • 台风必须收：大风预警优先于集雨，强制折叠防止网面与支架损坏——安全第一，集雨第二。
  • 本地兜底：若断网收不到预报，本地雨量计检测到雨也会张开，双路保险。

流程图 5 · 云端长势联动（含树冠日照与剪枝）

  • 固定机位 + 固定取景框：分析更稳定，避免角度漂移误判。
  • 树冠与日照是扩展项：同一张画面做树冠分割，结合太阳轨迹算各草坪分区的直射日照；日照不足且树冠扩大 → 生成剪枝任务卡（方向 / 覆盖比例 / 回缩建议），剪枝由人工执行。
  • 结果回流：诊断写回本地决策层，长势好自动降频，缺肥自动触发施肥——形成“看草说话”的闭环。

流程图 6 · 季节策略自动切换（全年视觉）

  • 按月份查表：系统内置 12 个月策略表（见「四季管理」），每月自动切换浇水频次、施肥开关、集雨与排水策略。
  • 雨天与低温叠加判断：梅雨月自动停水 + 启用排水；寒潮预警联动防冻布提醒；高温月“保命不催长”。
  • 目的唯一：草皮全年视觉呈现，而不是机械地“每天浇多少”。
💡 程序实现要点：ESP32 用 Arduino/ESP-IDF 轮询 + 中断；决策写成“条件全部通过才放行”的与门逻辑；所有动作落日志（时间 / 传感器值 / 触发源 / 结果），既方便排障，也是 7 寸屏曲线和季度影像的数据来源。华为 App 侧只做场景与开关，本地才是最终裁决者。
